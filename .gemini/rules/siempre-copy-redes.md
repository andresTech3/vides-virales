# Entrega obligatoria de Copy para Redes Sociales

Al completar cualquier vídeo en este proyecto (`toon-frenetico`, `cortos-animados`, `recreate` o cualquier composición nueva):
1. Entrega **SIEMPRE** en la respuesta final (sin esperar a que el usuario lo pida) el **Copy Optimizado para Redes Sociales**, adaptado para **TikTok**, **Instagram Reels** y **YouTube Shorts**:
   - **5 títulos virales** con alto factor de curiosidad.
   - **Caption / Descripción por plataforma** (TikTok, Instagram Reels y YouTube Shorts) con gancho en la primera línea, llamada a la acción (CTA) para generar comentarios/guardados y hashtags estratégicos.
   - **Tags SEO listos para copiar** (palabras clave separadas por comas para el campo de etiquetas/tags de YouTube Studio y buscadores).
   - **Prompt de miniatura** llamativa acorde al momento clímax del vídeo.
2. Guarda una copia en `salida/<slug>/copys.md`.
